# Guangzhou Frank Tech Co., Ltd. Website

Static multilingual foreign trade website for Frank / FLUTEK hydraulic pumps, motors, reducers and excavator hydraulic parts for the African aftermarket.

## Pages

- `index.html` - homepage with FLUTEK hero image, Frank company visual, brand-channel diagram and Africa service section.
- `products.html` - product catalog for K3V/K5V/K7V, K3VL, swing motors, travel assemblies, reducers and parts.
- `about.html` - company positioning and Africa-focused service story.
- `contact.html` - quotation form that opens WhatsApp with inquiry details.
- `404.html` - fallback page.

## Languages

English is the baseline text. Language files are stored in `lang/`:

- `en.json`
- `fr.json`
- `pt.json`
- `ar.json`
- `sw.json`
